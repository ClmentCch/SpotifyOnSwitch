# Exemple de carte SD

Copie le contenu de `MUSIC/` à la racine de la carte SD, puis ajoute :

- `MUSIC/PLAYLISTS/MANGER/1.mp3` et `2.mp3` : deux fichiers audio réels
  (MP3, WAV, FLAC ou OGG) ;
- `MUSIC/LOGO/playlist_manger.png`, `music_manger_1.png` et
  `music_manger_2.png` : les pochettes (PNG ou JPEG).

Les fichiers audio ne sont pas fournis : Musictt ne distribue aucune musique.
Sans pochettes, l'image de remplacement est utilisée automatiquement.
